\begin{abstract}
Scientific workflows are increasingly executed on heterogeneous infrastructures, which makes their efficient scheduling a challenging task.
This paper presents a lightweight scheduling approach that balances data locality against resource utilization.
We evaluate the approach with three benchmark workflows and show that it reduces the makespan by up to 23\,\% compared to a first-come-first-served strategy, while keeping the implementation effort low.

\keywords{Scientific workflows \and Scheduling \and Data locality \and Cloud computing}
\end{abstract}

\section{Introduction}\label{sec:introduction}
Scientific workflows describe the data flow between computational tasks~\cite{Winery}.
With the shift to cloud infrastructures, the question where each task runs determines both the runtime and the cost of a workflow~\cite{Binz2009}.
\lipsum[1]

The contribution of this paper is threefold: (i)~a scheduling heuristic that takes data locality into account, (ii)~an implementation on top of a standard workflow engine, and (iii)~an evaluation with three benchmark workflows (Section~\ref{sec:evaluation}).
