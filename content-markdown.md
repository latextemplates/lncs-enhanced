# Writing in Markdown {#sec:markdown-file}

This section is written in plain Markdown, not in \LaTeX{}.
Its source is the file `content-markdown.md`, which the main file includes with the `markdownInput` command of the [markdown package](https://ctan.org/pkg/markdown).
This needs \hologo{LuaLaTeX}.
Text can be *emphasized* or **bold**, and a citation looks like this [@mwe].
