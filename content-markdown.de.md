# Schreiben in Markdown {#sec:markdown-file}

Dieser Abschnitt ist in reinem Markdown geschrieben, nicht in \LaTeX{}.
Die Quelle ist die Datei `content-markdown.de.md`, die die Hauptdatei mit dem Befehl `markdownInput` des [markdown-Pakets](https://ctan.org/pkg/markdown) einbindet.
Dafür wird \hologo{LuaLaTeX} benötigt.
Text kann *hervorgehoben* oder **fett** sein, und ein Zitat sieht so aus [@mwe].
<#sec:markdown> zeigt mehr Markdown.
